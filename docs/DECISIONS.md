# Product decisions (2026-11-16)

- Independent repository, not part of RuleShift or Deep Tech Radar France.
- Free public-source project; no user registration.
- French and English from first version.
- Separate TAGE MAGE and GMAT tracks with shared game mechanics.
- Hybrid UI: playful game mode and serious timed mini-test mode.
- Adaptive difficulty implemented locally by transparent heuristics, not official scoring.
- Community contributions accepted via GitHub issues and pull requests with human review.
- Initial content is 36 original pilot questions; not yet editorially approved.
- Zero-cost target, static export and optional GitHub Pages after release sign-off.
