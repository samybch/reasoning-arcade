# Exam mapping and limits

Reference sites for later editorial verification:
- TAGE MAGE: https://www.tagemage.fr/page/sous-tests

| Game | TAGE MAGE pathway | GMAT pathway |
|---|---|---|
| Code Logic | Supplemental numeric/geometric logic warm-ups; not a full official Logic subtest representation | Not offered |
| Argument Lab | Reasoning and argumentation-related skills | Critical Reasoning-related skills |
| Enough Info? | Conditions minimales-related skills | Data Sufficiency-related skills |

The current preview is a **learning experiment**, not an official simulation. Some questions are elementary and not indicative of official test difficulty. Review exact answer conventions for both exams before calling anything exam-like. No score equivalence, affiliation or endorsement is claimed.

## Verification update — 16 November 2026

- **TAGE MAGE:** the official FNEGE outline describes the Logic subtest as numerical and spatial **categorization**, requiring an intersection of shared properties. Simple number-series drills remain warm-ups, not equivalent to the full official logic subtest. Six new pilot questions (`T-L-13`–`T-L-18`) extend numerical and spatial categorization.
  Source: https://www.tagemage.fr/page/sous-tests
- **Current GMAT:** GMAC places **Critical Reasoning** in Verbal Reasoning and **Data Sufficiency** in Data Insights. Quantitative Reasoning is a separate section. Data Insights additionally includes Multi-Source Reasoning, Table Analysis, Graphics Interpretation, and Two-Part Analysis.
  Source: https://www.mba.com/exams/gmat-exam/about/exam-content
- The GMAT consists of 64 questions across three 45-minute sections, and the TAGE MAGE has six 20-minute subtests. Reasoning Arcade's six-question mini-tests **do not reproduce either official exam format**.
  Sources: https://www.mba.com/exams/gmat-exam/about/exam-structure and https://www.tagemage.fr/page/sous-tests
- Four new original GMAT Data Sufficiency pilots (`G-D-13`–`G-D-16`) cover the median, conversion rates, renewals and standard deviation instead of only isolated equations.
- All new questions remain **pilot** content. No psychometric calibration or claim of official exam fidelity is established.

## Explicit exercise alignment — 16 November 2026

The current 46 pilot exercises are now classified as:
- **6 warm-ups:** `T-L-01` through `T-L-06`, numerical sequences for initial reasoning practice; not a simulation of the TAGE MAGE categorical Logic subtest.
- **40 targeted skill drills:** original questions based on broadly relevant reasoning skills, but **not** certified reproductions of official exam question formats or difficulties.

This classification is enforced in the question validator and displayed to players when an introductory warm-up is encountered.

### Coverage is not comprehensive

TAGE MAGE offers six subtests, and this MVP trains skills related to only three (Logic, Reasoning/Argumentation, Conditions minimales). GMAT has three sections, and this MVP offers Critical Reasoning skill drills and Data Sufficiency only, not the other Data Insights formats, Reading Comprehension or Quantitative Problem Solving.
